# TEST-022 — Historical BTC Research & Replay

This package adds the historical-data research and provenance layer.

Key principle:

> NEDA must be able to prove which source produced every historical observation
> used by the replay engine.

Run the unit tests:

    ~/local-ai/venv/bin/python -m unittest tests/test_neda_test022_historical_replay.py -v

TEST-022 does not enable live broker execution.

The live BTC adapter is intentionally separate from the historical CSV loader.
Historical option-chain data is never generated by this package.
